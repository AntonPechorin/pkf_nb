# pkf_nb

Простой сервис на FastAPI c логированием всех входящих HTTP-запросов в файл `logs/requests.log`.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер разработки:
   ```bash
   uvicorn app:app --reload
   ```

## Логирование запросов
* Каждый запрос записывается в `logs/requests.log` с методом, путем, кодом ответа, временем выполнения, user-agent и IP клиента.
* Файл логов автоматически создается; используется вращающийся обработчик (до 5 МБ, 3 резервные копии).
